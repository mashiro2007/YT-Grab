遇到「需要登录验证」

        
YouTube 有时会要求确认你不是机器人，尤其是数据中心网络。

        
用浏览器登录 YouTube，导出 cookies.txt，放到本程序目录后刷新页面。也可以在启动前设置环境变量 YTDLP_COOKIES_FROM_BROWSER=edge（Chrome 用 chrome，Firefox 用 firefox）。

关于画质与 FFmpeg

        
1080p 以上的视频通常把画面和声音分开提供，需要 FFmpeg 自动合并。勾选「兼容优先」会优先选择 H.264 + AAC，适合老设备；取消后可获得更高压缩效率的 AV1 / VP9 画质。

        
4K / 8K 文件较大，合并阶段可能需要比下载更长的时间，属正常现象。

      

      

        
文件保存在哪里？

        
默认保存在程序目录下的 downloads 文件夹。文件名采用「视频标题 [视频 ID]」格式，重复下载会自动添加序号，不会覆盖旧文件。
